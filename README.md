# ElectricityLoadDiagrams

Исследование потребления электроэнергии и кластеризация профилей клиентов.
Основной ноутбук: `notebooks/EDA_ElecricityLoad.ipynb`.
Прогноз нагрузки: `notebooks/ML_ElectricityLoad.ipynb` — подготовка данных,
суточный пример «как вчера», сравнение трёх базовых методов и эксперимент 3
с HistGradientBoostingRegressor на той же валидации.
Бизнес-задача описана в `BUSINESS_TASK.md`.

## Установка в Linux / облачной среде Codex

Выполняйте команды из корня проекта. Нужен `uv` или установленный Python 3.14.
При использовании `uv` версия Python берётся из `.python-version` (3.14.7).

```bash
bash scripts/dev.sh setup
bash scripts/dev.sh data
bash scripts/dev.sh lab
```

`setup` создаёт `.venv`, устанавливает зависимости, регистрирует ядро Jupyter
и запускает тесты. `data` загружает и распаковывает исходный датасет UCI;
существующий непустой файл не перезаписывается. `lab` запускает JupyterLab
на `127.0.0.1:8888` с аутентификацией по токену из вывода сервера.
Выберите ядро **ElectricityLoad (Python 3.14)**.

Повторная проверка окружения:

```bash
bash scripts/dev.sh check
```

Команды используют `.cache/` внутри проекта для кэша библиотек и служебных
файлов Jupyter, чтобы работать и при недоступном для записи домашнем каталоге.
Окружение, кэш и исходные данные исключены из Git.

## Установка в Windows (PowerShell)

Выполняйте команды из корня проекта. Если `.venv` уже создано, пропустите первую команду.

```powershell
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Активация окружения для этих команд не нужна. В текущем окружении используется Python 3.14.
`requirements.txt` включает библиотеки обработки данных, графиков, кластеризации
и средства запуска Jupyter. Их дополнительные зависимости pip устанавливает автоматически.
Встроенные модули `pathlib`, `sys`, `typing`, `itertools` и `unittest` устанавливать не нужно.
Версии основных зависимостей зафиксированы по проверенному окружению Python 3.14.

## Запуск ноутбука

```powershell
& .\.venv\Scripts\python.exe -m jupyterlab
```

Откройте `notebooks/EDA_ElecricityLoad.ipynb` и запустите ячейки по порядку.
При запуске через IDE выберите интерпретатор `.venv\Scripts\python.exe`
и это же окружение для ядра ноутбука.

Для анализа необходим `data/LD2011_2014.txt` (около 711 МБ).
Файл не хранится в Git. Для загрузки из
[официального источника UCI](https://archive.ics.uci.edu/dataset/321/electricityloaddiagrams20112014)
в Windows выполните:

```powershell
& .\.venv\Scripts\python.exe scripts/download_data.py
```

В Linux используйте `bash scripts/dev.sh data`. Архив занимает около 262 МБ,
распакованный файл — около 711 МБ. Во время анализа создаются дополнительные
таблицы в памяти, поэтому потребуется больше оперативной памяти, чем размер исходного файла.

## Проверка окружения и тесты

```powershell
& .\.venv\Scripts\python.exe -m pip check
& .\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты используют встроенный `unittest`; отдельная установка pytest не требуется.
Текущий код реализует EDA, кластеризацию, подготовку ML-данных, базовые суточные
прогнозы и первую модель HistGradientBoostingRegressor. Модель обучается один раз
на 2011–2013 годах; признаки каждого прогноза используют только завершившиеся дни.
Базовые методы и модель сравниваются на январе–июне 2014 года по MAE, RMSE и общему
WAPE; тест июля–декабря не используется для обучения или выбора метода.
