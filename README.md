# ElectricityLoadDiagrams

Исследование потребления электроэнергии и кластеризация профилей клиентов.
Основной ноутбук: `notebooks/EDA_ElecricityLoad.ipynb`.
Бизнес-задача описана в `BUSINESS_TASK.md`.

## Установка в Windows (PowerShell)

Выполняйте команды из корня проекта. Если `.venv` уже создано, пропустите первую команду.

```powershell
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Активация окружения для этих команд не нужна. В текущем окружении используется Python 3.14.
`requirements.txt` включает библиотеки обработки данных, графиков, кластеризации
и средства запуска Jupyter. Их дополнительные зависимости pip устанавливает автоматически.
Встроенные модули `pathlib`, `sys`, `typing`, `itertools` и `unittest` устанавливать не нужно.
Версии основных зависимостей зафиксированы по проверенному окружению Python 3.14.

## Запуск ноутбука

```powershell
& .\.venv\Scripts\python.exe -m jupyterlab
```

Откройте `notebooks/EDA_ElecricityLoad.ipynb` и запустите ячейки по порядку.
При запуске через IDE выберите интерпретатор `.venv\Scripts\python.exe`
и это же окружение для ядра ноутбука.

Для анализа необходим `data/LD2011_2014.txt` (около 711 МБ).
В этой копии проекта файл уже присутствует. Во время анализа создаются дополнительные
таблицы в памяти, поэтому потребуется больше оперативной памяти, чем размер исходного файла.

## Проверка окружения и тесты

```powershell
& .\.venv\Scripts\python.exe -m pip check
& .\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты используют встроенный `unittest`; отдельная установка pytest не требуется.
Текущий код реализует EDA и кластеризацию. Прогнозирование, описанное в бизнес-задаче
как этап 2, ещё требует реализации.
